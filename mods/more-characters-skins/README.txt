More Characters 2.1.0 - experimental expansion test pack

Requires the matching More Characters Expansion private game build.
Install this .nrm through Mods, enable More Characters, then restart the app.
Cycle past the original riders to select an added character. Each local player
can choose independently. Replace an older More Characters pack rather than
installing two copies. The optional HD texture mod remains separate.

25 appearances use the original male or female rider model and native riding,
combat and crash animations. The Turtle skins use painted shell detail with no attached shell geometry.
Terminator uses separate cheek textures for one-sided facial damage.
Gordon, the Turtles, Dredd and the human heads have dedicated face alignment.
Ghost Rider's flames are painted detail.

Your supported Road Rash 64 ROM supplies the original models and animations.
The archive contains authored texture payloads and mod metadata, not ROM data,
extracted models, original textures, native asset headers or saves.

Fan-made character interpretations; names belong to their respective owners.
Artwork was created with built-in image generation and fitted to native UVs.
Pillow performs offline conversion; no additional runtime image library.
