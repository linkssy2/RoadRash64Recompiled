# Road Rash 64 Recompiled — 1.4.5

An unofficial PC recompilation. **Bring your own Road Rash 64 USA v1.0 ROM.**
Windows and experimental native Linux builds.

## Start playing

1. Extract the complete Windows or Linux package to a writable folder.
2. **Windows:** open `RoadRash64Recompiled.exe`.
   **Linux:** make `RoadRash64Recompiled-x86_64.AppImage` executable and open it.
3. Choose **Select Game ROM**, select your supported ROM, then **Start Game**.
4. Open **Settings** to configure your controller, graphics and audio.

Keep the extracted files together and retain your saves/settings when updating.
Windows users can use `RoadRash64DirectStart.exe` to skip the launcher after setup.
For Linux requirements or AppImage startup help, see [Linux help](docs/LINUX_EXPERIMENTAL.md).

## Settings and optional mods

- Start with **50–60% Draw Distance**. At 100%, the entire map can load and reduce performance, especially in multiplayer.
- Install the separate **texture mod** or **More Characters** download through **Settings → Mods**. Extract the texture ZIP first to obtain its RTZ.
- For MK64 tracks, use the importer in **Settings → Mods** and supply your own supported Mario Kart 64 USA ROM. No ROMs or converted tracks are included.
- MK64 tracks/items and online play remain experimental. Online players need matching builds (protocol **68**) and matching imported packs.
